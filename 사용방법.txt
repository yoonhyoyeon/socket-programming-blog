====================================================
블로그 프론트엔드 - 사용 방법
====================================================

📦 필요한 것
  - Node.js (v16 이상)
  - npm

====================================================
🚀 실행 방법
====================================================

[1단계] 의존성 설치 (최초 1회만)
npm install

[2단계] 개발 서버 실행
npm run dev

[3단계] 브라우저 접속
http://localhost:5173

====================================================
🔧 API 서버 설정
====================================================

.env 파일에서 API 서버 주소 변경 가능:

[로컬 서버]
VITE_API_URL=http://localhost:8080

[ngrok 사용]
VITE_API_URL=https://abc123.ngrok.io

[다른 컴퓨터]
VITE_API_URL=http://192.168.0.10:8080

변경 후 개발 서버 재시작 필요!

====================================================
📦 배포 빌드
====================================================

npm run build

→ dist/ 폴더에 빌드 파일 생성
→ Vercel, Netlify 등에 배포 가능

====================================================
🌐 Vercel 배포
====================================================

[1] GitHub에 푸시
git add .
git commit -m "Add blog frontend"
git push

[2] Vercel 대시보드
- Import Project
- GitHub 저장소 선택
- blog_frontend 폴더 선택

[3] 환경 변수 설정
VITE_API_URL = http://your-server-ip:8080
또는
VITE_API_URL = https://your-ngrok-url.ngrok.io

[4] Deploy 클릭

====================================================
✅ 체크리스트
====================================================

[ ] Node.js 설치 확인: node --version
[ ] npm install 완료
[ ] .env 파일 확인
[ ] 백엔드 서버 실행 중
[ ] npm run dev 실행
[ ] 브라우저에서 접속 성공

====================================================
🐛 문제 해결
====================================================

[포트 충돌]
npm run dev -- --port 3000

[API 연결 실패]
- 백엔드 서버 실행 확인
- .env 파일의 URL 확인
- CORS 설정 확인

[빌드 오류]
rm -rf node_modules
npm install
npm run build
